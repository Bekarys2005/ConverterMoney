# ConverterMoney 
A simple Android app to convert currencies between RUB, USD, EUR, and KZT.

## Features 
- Convert money instantly between Russian Ruble (RUB), US Dollar (USD), Euro (EUR), and Kazakhstani Tenge (KZT)
- Clean and intuitive interface
- Real-time calculation
- Fetches latest conversion rates via API

## Tech Stack 
- Kotlin (or Java)
- Android Studio
- Standard Android libraries
- Any API libraries used
